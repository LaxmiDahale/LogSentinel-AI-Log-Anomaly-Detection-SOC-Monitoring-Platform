# LogSentinel AI — Portfolio Screenshots Guide

To showcase LogSentinel AI on your GitHub portfolio or LinkedIn, capture screenshots of the following core UI views:

## 1. Executive SOC Dashboard (`overview.png`)
- **View:** `📊 Executive Overview`
- **Highlights:** 8 KPI metric cards (Total Events, Total Alerts, Critical Alerts, Anomalies), Events Over Time area chart, Alert Severity pie chart, and Top Targeted Source IPs bar chart.

## 2. Splunk-Style Events Explorer (`events_explorer.png`)
- **View:** `🔍 Events Explorer`
- **Highlights:** Splunk query bar showing `status=failed | stats count by source_ip`, query result tables, and expanded Raw Event JSON view.

## 3. Security Alerts & Triage (`alerts_triage.png`)
- **View:** `🚨 Security Alerts`
- **Highlights:** Filtered alert list showing `CRITICAL` `SUCCESS_AFTER_BRUTE_FORCE` alerts with risk scores and status update dropdowns.

## 4. Analyst Investigation Workbench (`investigation_workbench.png`)
- **View:** `🔬 Incident Investigation`
- **Highlights:** Alert evidence timeline, affected entities card, recommended 5-step defensive playbook, and saved analyst case notes.

## 5. Machine Learning Anomaly Detection (`ml_anomalies.png`)
- **View:** `🤖 ML Anomalies`
- **Highlights:** Isolation Forest histogram distribution and outlier event list.

## 6. Security Reporting & CSV/JSON Export (`reporting_export.png`)
- **View:** `📄 Reports & Exports`
- **Highlights:** Executive summary metrics, top targeted users table, and CSV/JSON/Markdown download action buttons.
